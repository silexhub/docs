# Contributing to SilexHub documentation

[Documentation home](README.md)

Use an issue or pull request in this repository for a factual correction, an unclear explanation, or a proposed guide. Capability requests belong in the [developer hub](https://github.com/silexhub/silexhub/issues).

## Make a useful correction

Explain which page is affected, what is unclear or incorrect, and the evidence supporting the change. Keep current availability separate from product direction. A new configuration or command must be tested against the release it describes.

Keep links relative within this documentation repository. Use official links for other SilexHub repositories. Prefer one owning guide for a subject and link to it instead of copying long instructions across pages.

## Before submitting

Check links and examples, preserve the established SilexHub naming, and use synthetic examples. Do not include credentials, customer records, private configuration, internal code, or confidential data.

Maintainers review public contributions and reconcile accepted edits into the publication source before the next sync. A pull request is a proposal and does not automatically change the public service.
